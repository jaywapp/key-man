# WPF 화면 다듬기 분석

- orchestrator: Codex
- 요청: 공개 소개를 준비 중인 KeyMan WPF 화면을 보기 좋게 다듬는다.
- 기준: `feat/public-alpha-readiness`, 기존 공개 알파 작업을 보존한다.
- 현재: MainWindow는 기본 DataGrid·Button 외형에 큰 제목과 검색창을 배치한다. App.xaml의 공통 스타일은 여백뿐이며 선택·포커스·비활성 상태의 시각 체계가 부족하다. 추가 창은 기본 입력 컨트롤이 섞여 있다.
- 대상: Windows 개발자의 키 검색·목록 확인·복사·추가·삭제 흐름. Operate 모드로 가독성과 Windows 키보드 조작을 우선한다.
- 범위: 목록과 추가 창의 레이아웃, 타이포그래피, 색상, 공통 스타일, 선택·입력 상태.
- 비범위: 저장소·CLI·MCP·암호 처리 변경, 공개 배포, 새 기능 추가.
- 저장소 AGENTS.md에 따라 WPF 시안 3종을 제시했고 사용자가 "1안"으로 Clear Desk를 선택했다. 해당 시안의 운영 적용을 승인한 것으로 기록한다.
- 데모는 코드에 고정된 가짜 메타데이터만 사용한다. 실제 보관함·자격 증명·클립보드에 접근하지 않는다.

## 완료 기준

1. 동일한 콘텐츠로 서로 다른 구조의 WPF 시안 3종과 미리보기 제공.
2. 각 시안의 기본·작은 창·추가 창 렌더링, 키보드 포커스·명도 대비·긴 텍스트 확인.
3. 사용자 선택 후 운영 화면을 구현하고 기존 GUI 상태 테스트·빌드 및 렌더링 검증.
