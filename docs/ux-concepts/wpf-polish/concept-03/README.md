# 시안 3: Quiet Ledger

밝은 흰색 바탕과 짙은 녹색 글자를 사용하는 편안한 목록형 시안입니다. 제목에 충분한 여백을 주고 검색을 한 줄로 펼쳤습니다. 이름과 메모를 한 묶음으로 배치해 키의 용도를 먼저 읽고 서비스·환경·만료를 오른쪽에서 확인합니다. 행마다 상자를 만들지 않고 넉넉한 간격과 선택 배경으로 구분합니다.

메인 창은 1040×680을 기준으로 820×520까지 줄어듭니다. 목록은 남은 높이를 사용하며 긴 텍스트는 말줄임과 툴팁을 제공합니다. 추가 창은 500×660이며 입력 순서를 유지하고 폼 영역만 스크롤합니다. 버튼 영역은 하단에 남습니다. 기본 Windows 창 프레임과 네이티브 달력·환경 선택 동작을 유지합니다.

`impeccable`의 Operate 모드와 polish/craft-floor 원칙을 적용했습니다. `design-taste-frontend`는 랜딩 페이지용 규칙을 제외하고 위계·일관된 색상·상태 표현에 한정했습니다. 변화·모션·밀도는 4/1/4이며 시안에는 장식 애니메이션이 없습니다.

| 역할 | 색상 |
|---|---|
| 바탕 | `#FFFFFF` |
| 주요 글자 | `#183C2A` |
| 보조 글자·검색 안내 | `#52685A` |
| 주요 버튼 | `#245B3E` 바탕, `#FFFFFF` 글자 |
| 선택된 행 | `#E4F0E7` 바탕, `#183C2A` 글자 |
| 오류·삭제 글자 | `#9B3434` |
| 키보드 포커스 | `#245B3E` 2px 테두리 |

일반 글자/흰색 대비는 12.22:1, 보조 글자/흰색은 6.02:1, 버튼의 흰 글자/녹색은 7.95:1입니다. 선택된 행의 주요 글자는 10.43:1, 오류 글자/흰색은 7.16:1, 입력 테두리 `#7A9081`/흰색은 3.42:1입니다. 버튼의 키보드 포커스는 글자색과 같은 내부 테두리로 표시합니다.

메인 `SearchBox`, `KeyList`, `AddButton`, `CopyButton`, `DeleteButton`, `StatusLabel`과 추가 창의 필드 이름은 공통 프리뷰 실행기에 연결됩니다. 시안 파일 자체는 외부 리소스·운영 코드·실제 보관함에 의존하지 않습니다. 프리뷰의 복사는 상태 예시로만 동작해야 합니다.

작은 창에서는 3개 행을 모두 표시할 수 있는 공간이 줄어 목록 스크롤이 필요할 수 있습니다. 네이티브 ComboBox·DatePicker 내부 강조색은 Windows 테마의 영향을 받을 수 있으므로 통합 렌더에서 확인해야 합니다. 실제 WPF 렌더링·키보드 검증은 공통 프리뷰 단계에서 수행합니다.
