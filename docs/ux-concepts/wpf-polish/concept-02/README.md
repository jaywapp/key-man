# 시안 2: Night Console

짙은 차콜 바탕에서 키 목록과 선택 상세를 동시에 확인하는 WPF 시안입니다. 검색·추가는 상단에, 복사·삭제는 선택 상세 아래에 두어 작업 대상이 분명하게 보이도록 했습니다. 운영 코드와 보관함을 참조하지 않는 독립 loose XAML입니다.

방향은 네이티브 작업 화면이며 디자인 변화·모션·밀도는 `4 / 1 / 7`입니다. WPF 기본 컨트롤을 바탕으로 팔레트와 상태를 조정한 시안이며 공식 Fluent UI 구현으로 표방하지 않습니다.

- `Main.xaml`: 기본 1040×680, 최소 820×520. 목록과 상세를 `2.1* : 1*` 비율로 나누며 고정 폭의 상세 패널을 두지 않습니다. 긴 이름·메모는 상세 영역에서 줄바꿈하고, 높이가 부족하면 상세만 스크롤합니다.
- `Add.xaml`: 기본 500×660. 기존 필드 순서를 유지하고 본문만 스크롤하며 취소·저장은 하단에 둡니다. 비밀값 입력은 `PasswordBox`입니다.
- Segoe UI와 Malgun Gothic 폴백, 4/8 기반 간격, 5px 입력·버튼 모서리를 사용합니다. 기본 Windows 창 프레임을 유지합니다.
- 청록은 선택·주요 동작·키보드 포커스에, 연한 적색은 삭제와 오류에 사용합니다. 텍스트·테두리·선택 배경을 함께 사용해 색상만으로 상태를 전달하지 않습니다. 호버·눌림·비활성·빈 목록·선택 없음 상태를 포함합니다.

## 색 대비

| 용도 | 전경 / 배경 | 대비 |
|---|---|---|
| 본문 | `#EDF4F5` / `#151D21` | 약 15.3:1 |
| 보조 글자 | `#B6C7CC` / `#151D21` | 약 9.8:1 |
| 주요 버튼 | `#102B28` / `#70DBC8` | 약 9.0:1 |
| 입력 테두리 | `#657C84` / `#172125` | 약 3.7:1 |
| 오류 | `#FFB4AB` / `#151D21` | 약 10.1:1 |

키보드 포커스는 청록 테두리와 외곽 2px 표시를 사용합니다. 표 행은 선택 시 배경과 1px 테두리가 함께 바뀝니다. 주요 버튼의 호버·눌림 상태 대비는 각각 약 10.5:1, 6.5:1입니다. 애니메이션은 사용하지 않습니다.

## 프리뷰 연결과 남은 검증

요청된 `FindName` 이름을 유지했습니다. 목록의 `Name`, `Service`, `Environment`, `ExpirationStatus`, `Notes`는 공통 프리뷰가 주입하는 가짜 항목에 바인딩합니다. 실제 저장소·Windows 자격 증명·시스템 클립보드에 접근하는 코드나 이벤트 핸들러는 없습니다.

부모 세션에서 공통 프리뷰로 기본·작은 창·추가 창을 렌더링하고, 검색·선택·추가·삭제·가상 복사 상태 및 탭 포커스를 확인합니다. 사용자 선택 전 운영 XAML에는 적용하지 않습니다. 날짜 팝업의 달력 자체는 WPF 기본 테마를 유지하므로 해당 팝업의 키보드 동작과 명암 대비도 실제 실행에서 확인해야 합니다. Windows 고대비 설정 자동 대응은 이 고정 팔레트 시안에 아직 포함하지 않습니다.
