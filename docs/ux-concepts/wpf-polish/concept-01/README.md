# Clear Desk

Windows 앱의 익숙한 상단 검색·목록·하단 작업 구성을 유지한다. 이름 아래 메모를 두어 가로 열을 줄이고, 행 높이와 글자 굵기로 핵심 정보를 구분한다. 밝은 회색 바탕·흰 목록·절제한 파란색을 사용한다.

- 기본 글자: `#25364B`, 보조 글자: `#56657A`, 바탕: `#F3F5F8`.
- 주요 버튼: 흰 글자 / `#245FC1`, 대비 6.03:1.
- 검색 힌트: `#63738A` / 흰색, 대비 4.83:1.
- 검색·입력은 WPF 기본 키보드 동작, 버튼·표 셀은 명시적 포커스 표시를 유지한다.
- 메모·긴 이름은 행에서 말줄임하고 툴팁으로 원문을 제공한다.
- 기능·저장소 변경 없이 가장 작은 범위로 적용할 수 있어 권장한다.
