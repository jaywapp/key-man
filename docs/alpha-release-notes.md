KeyMan은 Windows 개발자를 위한 로컬 API 키·토큰 보관함입니다. GUI·CLI·stdio MCP가 같은 Windows 자격 증명과 메타데이터를 사용합니다.

이번 알파에서는 여러 실행 경로의 동시 변경을 직렬화하고, GUI의 오래된 목록 저장과 초기 로드 실패 후 덮어쓰기를 방지했습니다. `.env` 가져오기는 CLI의 같은 저장 경로를 사용하며, GUI·MCP 클립보드 정리와 오류 복구를 보완했습니다.

WPF 화면은 밝은 Clear Desk 스타일로 정리했습니다. 이름과 메모를 함께 읽을 수 있는 목록, 긴 텍스트 툴팁, 구분된 검색·빈 상태 안내, 작은 창에서도 보이는 저장·취소 버튼과 입력 오류 안내를 제공합니다.

## 설치

- `KeyMan-Setup-<version>.exe`와 같은 이름의 `.exe.sha256` 파일을 내려받아 SHA-256을 비교하세요.
- Windows x64용입니다. .NET 10 런타임을 포함하므로 별도 SDK 설치는 필요하지 않습니다.
- 현재 설치 파일에는 코드 서명이 없습니다. 체크섬은 파일 일치 확인용이며 배포자의 신뢰를 대신하지 않습니다.
- 기본 경로는 `%LOCALAPPDATA%\Programs\KeyMan`입니다. PATH 추가를 선택했다면 새 터미널에서 `key-man.exe --help`를 실행할 수 있습니다.
- KeyMan은 MIT 라이선스를 따릅니다. 설치 폴더의 `LICENSE.txt`에 원문, `ThirdPartyNotices`에 외부 구성요소의 라이선스·고지문이 있습니다.

업데이트할 때는 GUI와 MCP 클라이언트를 정상 종료하고 새 설치 파일을 같은 경로에 설치하세요. 자동 업데이트는 없습니다. Windows의 설치된 앱에서 제거할 수 있으며, 설치 프로그램이 추가한 PATH·KEYMAN_HOME은 제거하지만 사용자 키와 메타데이터는 보존합니다. 자세한 절차는 [설치·업데이트·제거 안내](https://github.com/jaywapp/key-man/blob/main/docs/installer.md)를 참고하세요.

## 알파의 범위와 제한

- 개발·평가용 알파입니다. 가짜 값으로 먼저 설치와 사용 흐름을 확인해 주세요.
- MCP 도구 응답에 비밀값을 넣지 않습니다. 셸 권한을 가진 AI나 같은 Windows 사용자 권한의 프로그램으로부터 키를 격리하는 제품은 아닙니다.
- GUI·MCP는 30초 뒤 또는 정상 종료 시 자신이 복사한 클립보드의 정리를 시도합니다. CLI `copy`, 클립보드 기록·동기화 사본, 강제 종료 후 삭제는 보장하지 않습니다.
- 팀 공유·클라우드 동기화·자동 업데이트·키 자동 회전·완전한 백업/복원 기능은 없습니다. JSON만 복사해서는 비밀값을 백업할 수 없습니다.
- 정상 오류의 저장 복구는 수행하지만 Windows 자격 증명 관리자와 JSON 사이의 전원 차단·강제 종료까지 완전한 원자성을 보장하지 않습니다.
- 앱을 제거해도 사용자 키와 메타데이터는 보존됩니다.
