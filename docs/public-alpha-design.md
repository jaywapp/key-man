# 공개 알파 설계

## 데이터 보존

메타데이터 저장소는 같은 vault 경로에 대해 프로세스 간 파일 잠금을 획득한 뒤 최신 데이터를 읽고 변경·저장을 수행하는 트랜잭션 API를 제공한다. 비밀값 저장/롤백도 변경 콜백의 같은 배타 구간에서 수행한다. 파일 교체는 고유 임시 파일을 사용하고 실패 시 원본을 보존한다. GUI는 오래된 화면 목록을 저장 원본으로 쓰지 않고 성공한 최신 스냅샷으로 화면을 갱신한다. 초기 로드 실패 시 쓰기를 차단한다.

importer는 직접 JSON/자격 증명을 중복 구현하지 않고 같은 CLI 경로를 사용하도록 정리한다. 입력 값은 stdin으로 전달하고 로그·프로세스 인수에 포함하지 않는다. 0·1·여러 항목 및 실패 시 보존을 검증한다.

## 클립보드와 MCP

GUI는 30초 뒤 또는 정상 종료 시 자신이 복사한 내용이 여전히 현재 내용인 경우만 지운다. MCP도 복사 수명과 정상 종료 처리를 명확히 한다. 클립보드 기록·동기화·강제 종료에 대한 보장을 하지 않는다. CLI는 즉시 종료하는 복사 명령의 동작을 명시적으로 문서화한다. MCP 강제 교체 가능 도구는 파괴적 변경으로 표시한다.

## 배포

후속 사용자 승인에 따라 로컬 후보를 feature 브랜치에 커밋·push하고 원격 CI를 검증한 뒤 PR을 병합한다. main의 수동 릴리스 워크플로로 `1.1.0-alpha.1`을 발행하고, 실제 자산·체크섬을 확인한 후 README·설치 안내의 준비 상태를 현재 배포 상태로 바꾼다. 문서 후속 변경도 PR로 병합하며 main에 직접 커밋하지 않는다.

.NET 10 LTS를 공통 기준으로 사용한다. PR과 main에서는 빌드·전체 회귀 검증을 실행하고, 릴리스는 명시적인 수동 실행으로 버전을 지정해 prerelease로 발행한다. 실행 번호를 안정판 버전으로 사용하지 않는다. installer와 SHA-256 체크섬을 함께 준비한다. 아티팩트 업로드 실패가 승인된 릴리스 업로드를 막지 않도록 배포와 검증 산출물을 구분한다.

## 사용자에게 보여줄 결과

사용자가 승인한 MIT 원문을 루트 `LICENSE`에 두고 설치 폴더의 `LICENSE.txt`로 배포한다. README·기여 안내·릴리스 노트에 같은 조건을 안내한다. 외부 구성요소의 고지는 `ThirdPartyNotices`에 별도로 유지한다. 설치 검증에서는 배포된 라이선스의 SHA-256을 저장소 원문과 비교한다. 원문 기준은 [OSI MIT](https://opensource.org/license/mit)다.

README는 대상 사용자→실제 화면→설치→첫 키 등록→GUI/CLI/MCP 사용→보안 경계 순으로 구성한다. 실제 발행된 알파 버전과 다운로드 링크를 안내하고 저장소 공개 여부와 구분한다. 설치 파일의 서명 여부·지원 OS/아키텍처·데이터 보존·업데이트 방법을 설명한다. 민감정보가 없는 데모만 기록한다. 후속 사용자 요청으로 선택된 Clear Desk UI는 별도 wpf-polish 문서에 따라 적용했다.

## 검증

동시 등록과 오래된 GUI 스냅샷, 손상/잠긴 파일, importer 배열 경계, 실패 복구를 테스트한다. CLI와 MCP 및 설치된 실행 파일을 가짜 데이터로 확인한다. 저장소 및 이력의 시크릿 패턴 검사는 값 없이 결과만 보고한다. 빌드·설치·문서 링크·공개용 이미지 검증 결과를 작업 문서에 기록한다.

## 클립보드 소유권 보완

Win32 창 정리까지 완료한 뒤 배타 구간을 다시 열어 복사별 GUID 표식을 확인하고 변경 번호를 캡처한다. 중간에 다른 앱이 덮어썼으면 소유권 없음(0)을 반환한다. 삭제는 0을 거부하고 배타 구간 안에서 변경 번호를 비교한다. 표식만으로 삭제하지 않아 이후 복사 변경도 보호한다.
