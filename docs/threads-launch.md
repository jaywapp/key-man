# Threads 공개 초안과 게시 점검

이 문서는 게시할 원고와 데모 순서를 준비한 것이다. `v1.1.0-alpha.1` 릴리스와 README를 정리했다. 저장소는 아직 비공개이며 Threads에는 게시하지 않았다. 공개 전환과 비로그인 다운로드를 확인한 뒤 아래 원고를 사용한다.

## 본문 초안

API 키가 필요할 때마다 여러 프로젝트의 .env를 뒤지는 게 번거로워서 KeyMan을 만들었습니다.

Windows 로컬 키 보관함입니다. GUI로 서비스·환경별로 찾고, CLI로 스크립트에 연결하고, Codex·Claude Code에서는 MCP로 목록 조회·등록·복사를 요청할 수 있어요.

실제 값은 Windows 자격 증명 관리자에 저장하고, MCP 도구 결과에는 비밀값을 보내지 않습니다.

첫 공개 알파입니다. Windows 개발자분들의 설치·사용 피드백을 받고 싶습니다.

https://github.com/jaywapp/key-man

## 후속 댓글 초안

현재 범위는 개인 Windows 로컬 사용입니다. 팀 공유·클라우드 동기화·키 자동 회전은 없습니다.

MCP 응답에 값을 넣지 않지만, 셸 권한이 있는 AI나 같은 사용자 권한의 프로그램에서 키를 격리하는 도구는 아닙니다.

GUI·MCP는 30초 뒤 또는 정상 종료 시 자신이 복사한 클립보드의 정리를 시도합니다. CLI 복사는 자동 삭제하지 않고, 클립보드 기록·동기화 사본도 삭제를 보장하지 않습니다.

설치와 제한 사항은 README에 정리했습니다. 가짜 키로 먼저 사용해 보시고 불편한 흐름을 알려주세요.

## 30초 데모 시나리오

데모용 별도 메타데이터와 고유 식별자의 가짜 credential만 사용한다. `KEYMAN_VAULT_PATH`는 메타데이터 위치만 바꾸므로 실제 자격 증명 관리자도 별도로 격리된다고 가정하지 않는다. 개인 보관함, `.env`, 브라우저 계정, 실제 클립보드는 화면에 띄우지 않는다.

| 시간 | 화면과 동작 | 전달할 내용 |
|---|---|---|
| 0–5초 | 가짜 항목만 있는 GUI 목록 | 서비스·환경별로 찾는 로컬 보관함 |
| 5–11초 | `Demo` 검색, Development 항목 선택 | 검색과 만료 상태 |
| 11–16초 | GUI의 복사 버튼과 상태 문구 | 비밀값을 화면에 표시하지 않고 복사 |
| 16–22초 | 터미널에서 `key-man.exe list Demo` | 같은 항목을 CLI에서도 사용 |
| 22–30초 | MCP 클라이언트의 목록 또는 복사 요청과 성공 결과 | MCP 응답에는 이름·결과만 표시 |

30초 뒤 정리 동작을 확인하는 장면은 복사 직후부터 30초 이상 연속 촬영한 별도 클립으로 남긴다. 짧은 소개 영상에서 시간 경과를 생략하면서 실시간 검증처럼 표현하지 않는다. 테스트용 값이라도 `get` 결과를 노출하는 장면은 기본 데모에서 제외한다. README의 이미지는 실제 앱 XAML을 가짜 데이터로 렌더링한 정적 예시이므로 촬영 영상으로 소개하지 않는다.
